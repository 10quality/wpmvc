WordPress MVC documentation has been moved!

<!-- truncate -->

First of all, let me apollogice with developers who were dependent on the previous documentation site. I personally was unable to continue supporting the hosting anymore.

The WordPress MVC (WPMVC) documentation website has been moved from https://wordpress-mvc.com to [https://10quality.github.io/wpmvc](https://10quality.github.io/wpmvc).


## The reasons

1. To reduce hosting costs.
2. To have the documentation in the same repository.
3. To use existing documentation frameworks.

### Hosting costs

While having the framework located at wordpress-mvc.com provided great SEO and web positioning, in the end, it is open-source and has not received any funding.

Paying for monthly hosting costs is not worth it moving forward.

### GitHub pages

WPMVC is fantastic, should not be abandoned.

Realocating its documentation to GitHub pages made a lot of sense moving forward, as it will allow for community contribution and easier maintenance.

## Maintainability

Docusaurus is a robust documentation open-source framework that aligned perfect with the WPMVC and GitHub pages.

It allows for easy maintainability through Markdown pages and custom React components.


## Moving forward

I personally hope that the framework can grow from here and that the new documentation site provides great exposure.

There are many new design patterns and best practices that can be integrated to make it more powerful.
